# Power BI Dashboard

This folder contains the Power BI dashboard developed to analyze sales performance and communicate key business insights.

The dashboard includes:
- Monthly sales trends
- Sales by product line
- Sales by country
- Sales by deal size
- Sales performance by year
- Key Performance Indicators (KPIs)

The dashboard was designed to support data-driven decision-making by highlighting sales trends, high-performing products, markets, and customer segments.
